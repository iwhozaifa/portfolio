problem: Learning DevOps means thousands of free resources, no order to them and nothing that tells you whether you learned anything.
built:
  - A day-by-day curriculum built from open resources, with a quiz after each day, a timed CKA practice exam, hands-on tasks with hints and solutions, and guided projects such as a CI/CD pipeline and a Linux server setup.
  - Progress earns XP, badges and streaks. Subjects are JSON files, so adding one needs no code. An admin panel tracks learners and logs every admin action.
