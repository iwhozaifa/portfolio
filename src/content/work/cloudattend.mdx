problem: Roll call wastes lecture time, and a static attendance code can be passed to friends who aren't in the room.
built:
  - A serverless attendance app. Teachers create courses, enrol students by email or roll number and open a session that shows a QR code signed with HMAC, valid for 45 seconds and replaced before it runs out.
  - Students scan it in the app, open it from the phone camera, or paste it. Teachers watch the live list, close the session and download reports against an attendance threshold as CSV. Administrators promote users to teachers.
architecture:
  lanes:
    - name: Check-in
      stops:
        - label: Student's phone
        - label: CloudFront
          detail: OAC, security headers
        - label: API Gateway
          detail: HTTP API, Cognito JWT authorizer
        - label: Lambda
          detail: one router, its own IAM role
        - label: DynamoDB
          detail: five tables, conditional writes
    - name: Sign-up
      stops:
        - label: Browser
        - label: Cognito
          detail: email code, password reset
        - label: PreSignUp Lambda
          detail: reserves the roll number, rejects duplicates
        - label: PostConfirmation Lambda
          detail: writes the profile, adds the student group
  beside:
    - name: Beside the API
      items:
        - label: Secrets Manager
          detail: the QR signing key
        - label: S3
          detail: the React app, private behind CloudFront
        - label: CloudWatch
          detail: Lambda error and API 5xx alarms
  footnote: All of it is AWS CDK, with assertion tests on the synthesized template.
hard:
  statement: Saving a check-in only after six checks, with the duplicate check done atomically.
  body: The API checks identity and role, course ownership and enrolment, the session's state, the token's signature and its expiry, then writes the check-in with a DynamoDB conditional write so the same student can't be counted twice. A local mode runs the real API router against in-memory data, so every journey is tested without AWS.
